# Ujjwal Gupta | Premium Full Stack Developer Portfolio

A modern, responsive, and high-performance personal portfolio website built with **React.js**, **Tailwind CSS**, and **Lucide Icons** showcasing the verified background, skills, internship experiences, and project portfolio of **Ujjwal Gupta**.

---

## 🌟 Key Highlights & Structure

1. **Navigation Bar** (`Navbar.jsx`): Sticky glassmorphic navbar with active section observer, smooth scrolling, mobile drawer menu, and quick resume viewer.
2. **Hero Section** (`Hero.jsx`): High-impact introduction with glowing radial gradients, developer terminal peek, verified status tags, and direct CTAs.
3. **About Me** (`About.jsx`): Authentic professional narrative reflecting background from Prayagraj, UP, academic status in Noida at AKGEC, multi-language coding foundations, and extracurricular passion for art & craft.
4. **Technical Skills** (`Skills.jsx`): Interactive categorized skills showcase with category filters and icons for all languages, frontend, backend, frameworks, and developer tools (no artificial ratings).
5. **Featured Projects** (`Projects.jsx`): All 11 verified personal web applications with interactive category tabs, custom SVG banner cards, verified API indicators, and an interactive **Live Demo Modal** (`ProjectModal.jsx`) featuring live interactive simulators.
6. **Internship Experience** (`Experience.jsx`): Clean vertical timeline detailing all 3 professional internship experiences at **BeeSkilled**, **Vault of Code**, and **UptoSkills**.
7. **Education** (`Education.jsx`): Academic milestones covering Computer Science at **Ajay Kumar Garg Engineering College (AKGEC)**, **NIOS Class 12 (2025)**, and **UP Board Class 11 (2023)**.
8. **Beyond Coding** (`Interests.jsx`): Personal interests including Art & Craft, Exploring New Technologies, and Creative Prototyping.
9. **Contact Me** (`Contact.jsx`): Complete contact form with client-side validation, confetti feedback, direct verified GitHub and LinkedIn profile links, and editable email/phone placeholders.
10. **Curriculum Vitae Modal** (`ResumeModal.jsx`): Full printable and downloadable resume viewer.

## 🛠️ Technology Stack

- **Frontend Library:** React 18
- **Styling:** Tailwind CSS (utility-first, responsive, custom dark theme `#0B0F19`)
- **Iconography:** Lucide React
- **Build Tool:** Vite
- **Typography:** Inter & Poppins (Google Fonts)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Running Locally
```bash
# Clone the repository / navigate to project folder
cd "C:\Users\ujjwa\OneDrive\Desktop\Resume"

# Start the Vite development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Building for Production
```bash
# Create an optimized production build
npm run build

# Preview production build locally
npm run preview
```

The production assets will be output in the `dist/` directory, ready for immediate deployment on platforms like **Vercel**, **Netlify**, or **GitHub Pages**.
